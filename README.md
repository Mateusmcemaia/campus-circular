# Campus Circular Hub

"Aja como um Engenheiro Front-End Sênior. Preciso desenvolver o frontend de um PWA (Progressive Web App) focado em economia circular dentro de um campus universitário, utilizando React, TypeScript, Tailwind CSS e Vite.

A aplicação deve ter responsividade completa, funcionando como uma Landing Page rica no desktop e com experiência fluida de aplicativo no mobile.

Requisitos da Interface:

Página Inicial (Landing Page Pública):

Hero section com uma explicação da proposta de economia circular no campus e dois CTAs claros ("Quero Anunciar" e "Buscar Itens").

Uma seção com 3 estatísticas simuladas do sistema (ex: Itens doados, Estudantes impactados, Reais economizados).

Uma "Vitrine Pública" (Grid de cards) listando os anúncios. Cada card deve ter foto, título, preço (ou tag de Doação) e categoria.

Filtros básicos acima da vitrine pelas categorias: 'Livros', 'Engenharia', 'Computação', 'Eletrônicos', 'Outros'.

Área Autenticada (Visão Mobile PWA):

Um formulário limpo para cadastrar um novo item com os campos: Título, Descrição, Categoria (Select), Preço ou Doação (Radio/Toggle), e uma URL de imagem (Input de texto simples).

Uma aba/tela onde o usuário pode visualizar os seus próprios anúncios cadastrados com um botão de excluir.

Requisitos Técnicos e Bônus:

Crie um design polido, moderno, com feedback visual de carregamento e transições suaves entre as telas.

Utilize componentes do shadcn/ui se possível.

IMPORTANTE: O código deve incluir as configurações básicas para ser um PWA válido, incluindo a chamada para um manifest.json e o registro de um Service Worker simples."
